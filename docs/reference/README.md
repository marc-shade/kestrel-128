# Reference observations

Early observations that shaped the native system: an inventory of the local
GEOS 128 disks used as a comparison point, the first GEOS 128 boots in VICE,
and the experiment that settled where the native VIC screen lives.

Like the [validation records](../validation/README.md), these were made during
Kestrel 128's development under the earlier name uOS 128, and the paths and
commit hashes they cite belong to that private history. Only each folder's
README, its observations and its checksum list are published; the captured
screens, memory dumps, disk images, logs and capture scripts they list are not,
so links to those files do not resolve here. Home-directory paths, local
network addresses and the agent's email address were replaced as described
in the [validation records' README](../validation/README.md).
